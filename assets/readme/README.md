# README 视觉素材

这些素材仅用于仓库主页，不参与站点构建。

| 文件 | 来源与用途 |
| --- | --- |
| `cover.svg` | 原创品牌封面；使用站点的 `#f4f4f0`、`#0a0a0a`、`#ff4d00`，延续方框、圆形与斜线构图。 |
| `footer.svg` | 原创页尾，与封面使用同一色彩和字体回退。 |
| `home.jpg` | 本地 `index.html` 的真实浏览器截图。 |
| `articles.jpg` | 本地 `blog.html` 的真实浏览器截图，展示分类、标签与关键词入口。 |
| `coffee.jpg` | 本地 `coffee.html` 的真实浏览器截图，展示咖啡档案与最近冲煮。 |

拍摄日期：2026-10-07。来源：`wip/lifestyle-redesign` 分支的工作区，使用 Python 静态服务器与 Chromium，桌面视口 1440 × 1000。首页和文章页分别截取顶部 740 与 850 像素，避免下一内容区被截断；咖啡页保留完整视口。等待入场动效完成后截图，没有替换页面文案或注入演示数据。截图中的咖啡器具图沿用页面上的产品资料图及来源说明，不是作者实拍。

截图按原比例展示，可点击进入对应线上页面。页面内容、布局或品牌样式变化后，应重新拍摄；线上版本与当前分支可能不同。SVG 使用常见中文无衬线字体回退，不依赖外部图片、脚本或字体服务。
