## 维护方式

```bash
pip install -r requirements.txt
npm ci
npm run build
npm test
python3 validate_site.py
python3 generate_search_index.py
python3 generate_sitemap.py
python3 -m http.server 8000
```

直接维护 HTML；样式在 styles/ 中修改，utility 类变化后重新编译 CSS。
